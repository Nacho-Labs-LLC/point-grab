# @point-grab/web-components

Web Components adapter for point-grab.

## Install

```bash
npm install @point-grab/core @point-grab/web-components
```

## Usage

```ts
import { initPointGrabWebComponents } from '@point-grab/web-components';

initPointGrabWebComponents();
```

## What it adds

- traverses into Shadow DOM for inspection
- maps custom element tags back to constructors when possible
- helps capture custom element structure more cleanly

Docs: https://point-grab.com
