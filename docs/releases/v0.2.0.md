# Point Grab v0.2.0

**Draft — not published to npm.** This coordinated release covers core, Angular, React, Solid, Svelte, Vue, Web Components and the MCP server.

## Breaking change: activation shortcut

The default activation shortcut is now **Ctrl+B on every platform**, including macOS (Control, not Command). Native Ctrl+C/Cmd+C remains normal browser copy. Hold is still the default; toggle mode and custom modifier combinations are supported. Existing integrations that require the previous shortcut can explicitly configure `activationKey`.

## Highlights

- Configurable Freeze key (default F), with consistent cleanup on Escape, disable, toolbar exit and dismissal. Editable fields, including open-shadow inputs, retain their native keyboard behavior.
- Current-page region capture with mandatory privacy preview and comment, explicit acknowledged image submission, Retake and failure/retry handling. Open shadow content and exportable 2D canvas are supported with documented rendering limitations.
- Correct history re-copy for pending grabs; denied clipboard confirmation preserves queued comments. Inspector cursor styling is excluded from copied computed styles.
- Responsive comment/confirmation controls and corrected overlay stacking keep interactive controls above inspection labels and transient feedback.
- Solid adapter and development JSX source instrumentation join the supported framework integrations. All seven demos are maintained only under `examples/`; StackBlitz delivery is a separate pending step, not a published feature of this draft.
- Expanded real-browser journeys and opt-in review recordings with protected output paths, independent test inventories and focused-test rejection. Publication uses the exact verified pnpm tarballs, not repacked workspace directories.

## Capture and transport boundaries

Screenshots are DOM-rendered approximations of the current page, not arbitrary-screen/OS pixels or image-clipboard capture. Privacy redaction is not a security boundary: inspect the mandatory preview. Freeze pauses visible DOM/animations, not JavaScript execution or application state. See [capture contract](https://github.com/Nacho-Labs-LLC/point-grab/blob/naterchrdsn/recover-inflight-work-release/docs/screen-grab.md).

The webhook defaults to loopback. Hosted previews need the correct trusted Origin and browser network permission; a health response alone does not prove image submission is authorized. Do not expose the listener broadly to make a demo work.
