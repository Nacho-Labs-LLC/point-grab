Angular example

point-grab for Angular

A real Angular demo surface for inspecting nested cards, metrics, and action controls. Hold Ctrl+C / Cmd+C, hover an element, and click to capture it.

What this proves
  • Angular app initialized from main.ts with initPointGrabAngular()
  • Nested standalone components for better component ancestry capture
  • Enough UI density to be worth inspecting

Best results

  1. Run npm run dev or ng serve for Angular debug metadata.
  2. Hold the activation keys before hovering your target.
  3. Click cards, buttons, or the detail panel to inspect deeper nested nodes.
Why this exists
