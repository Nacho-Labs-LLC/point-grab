The developer side

From detail to direction.

  1. Explore the feed. Like a post, expand its component detail, or write a reply. Changes stay in this tab.
  2. Inspect the real component. Hold Ctrl+C / Cmd+C, hover a post or action, then click. Selected text still copies normally.
  3. Keep a fleeting moment. Hover or focus the live signal below; use Freeze (F) in the picker. Escape resumes the page.
  4. Explain the change. Add an element comment, or Actions → Add screenshot, drag a current-page region and review before Send.
✦A small idea in motion. Freeze (F) holds this detail and the signal; Escape resumes.

Capture reconstructs DOM, not browser pixels. Inputs are redacted; filters, shadow DOM, canvas, frames and cross-origin images can block it. This glass-style Angular surface intentionally demonstrates the filter limitation. Send needs the local MCP server at localhost:3456 and confirms only after acknowledgement.
